# Hostel Management Application

Created using MERN Stack with Redux

## Installation

```
npm install
cd frontend && npm install
```

### Configure .env file

```
NODE_ENV = development/production
PORT = 5000
MONGO_URI= Mongo Uri
JWT_SECRET= JWT Key
```
